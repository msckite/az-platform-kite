# Upgrade path

These guides list what a consuming repository must change when it moves to a newer Kite release.
Each release also has release notes on its GitHub Release.

Find the guide that starts at the version you run. When you move across several releases, work
through the guides from the oldest to the newest. The newest guide is listed first.

| From | To | Guide |
| --- | --- | --- |
| v1.1.x | v2.0.0 | [Upgrade path from v1.1.x to v2.0.0](./v1.1.x-to-v2.0.0.md) |
| v1.0.x | v1.1.0 | [Upgrade path from v1.0.x to v1.1.0](./v1.0.x-to-v1.1.0.md) |

A release that needs no change in a consuming repository has no guide.
