# Upgrade path from v2.0.x to v3.0.0

`New-PlatformWorkflow -WorkflowType both`, the default, now installs the `infra` and `workload`
bundles. It used to install `platform` and `workload`.

## Check your `New-PlatformWorkflow` calls

If you call `New-PlatformWorkflow` without `-WorkflowType`, or with `-WorkflowType both`, the
command now installs the infra bundle and no longer installs the platform bundle. Files you already
have are never overwritten unless you add `-Force`, so existing repositories keep their platform
workflows.

To get the old result, pick one of these:

| You want | Run |
| --- | --- |
| Platform and workload | `New-PlatformWorkflow -WorkflowType platform`, then `New-PlatformWorkflow -WorkflowType workload` |
| Platform, workload and infra | `New-PlatformWorkflow -WorkflowType all` |

Pass `-WorkflowType platform` explicitly in scripts that install the platform bundle, so they no longer depend on the default.
