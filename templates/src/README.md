# Source Code

## Development Guidelines

> [!IMPORTANT]
> This directory contains the application source code managed by the Development Team.
>
> **Before making changes:**
> - Create a feature branch from the latest `main` branch
> - Follow the contribution guidelines outlined in [CONTRIBUTING.md](../CONTRIBUTING.md)
> - Submit changes via Pull Request for code review
> - Ensure all tests pass before requesting review
>
> **Need help or want to report an issue?**
> - Refer to [SUPPORT.md](../SUPPORT.md) in the root folder for guidance
> - File a GitHub issue for _bugs_, _feature requests_, or _questions_
>
> All code changes must go through the proper review process to maintain code quality, security, and team collaboration standards.
