# Workflow templates

This folder holds the GitHub Actions workflow templates that `New-PlatformWorkflow` copies into your
repository. The documentation lives in `docs/`:

- To use the workflows in your repository, read the
  [workflows guide](../../../docs/consumers/workflows/README.md).
- To change the templates themselves, read the
  [workflow templates maintainer guide](../../../docs/contributors/workflow-templates.md).
